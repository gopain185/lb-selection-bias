# Public LB Selection Bias Grid

Simulated selection bias of the best public-leaderboard score among N correlated submissions: how far its public score
sits above its true and private scores.

## Provenance

Fully synthetic. Generated by `selbias/run.py` (repository `lb-selection-bias`, MIT; the code is also embedded in
the companion notebook "How Much Does the Best Public Score Overstate"). No competition data, no personal data.

## Generation

- One reference correctness vector per trial: each row is right with probability 0.62.
- Each submission flips each row's correctness with probability `q`, independently. The counts come exactly from
  binomials.
- Optionally, each submission gets a true offset drawn from N(0, spread), added to its public and private scores.
- The submission with the best public score is selected. 4,000 trials per cell, one fixed seed per cell
  (1000 + cell index).

Grid: n_public in {600, 1200, 3000}; n_private = 4 x n_public; n_subs in {1, 2, 5, 10, 20, 50}; q in
{0.01, 0.025, 0.05, 0.1}; spread in {0, 0.002, 0.005}. 216 rows.

## Columns (`grid.csv`)

| column | meaning |
| --- | --- |
| n_public, n_private | rows in the public and private parts |
| n_subs | number of submissions selected from |
| acc | reference accuracy (0.62) |
| q | per-row flip probability of each submission against the reference |
| spread | sd of the true offsets between submissions (0 = all equally good) |
| optimism_vs_true | mean of (public score - true score) of the selected submission |
| optimism_vs_private | mean of (public score - private score) of the selected submission |
| sd_optimism_vs_private | sd of that difference across trials |
| true_regret | mean of (best true score - true score of the selected one) |
| picked_true_best | share of trials where the selected one is the truly best (NaN when spread = 0) |
| public_range | mean of (best - worst public score) |
| pairwise_flip | 2q(1 - q), the expected share of rows two submissions disagree on |
| rough_rule | sqrt(q(1 - q) / n_public) x E[max of n_subs standard normals] |

## Intended use

Judging whether a new submission that scores below the current best public score is really worse, and setting a
realistic baseline for "the score to beat" late in a competition.

## Known limitations

- Flips are independent across rows and submissions. Real submissions share their disagreements, so their effective
  number is smaller than their count.
- Plain accuracy, not balanced accuracy or other metrics.
- One reference accuracy (0.62). Results depend on q(1 - q), not on the accuracy itself.
- Monte Carlo error: about 0.0001 to 0.0003 on the optimism columns.
